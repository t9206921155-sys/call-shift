## CallShift 0.8.4-max-setup — исправление настройки профиля MAX

Подписан тем же ключом, fi.callshift.app, versionCode 36. Ставится поверх предыдущей
версии без удаления. Экспортируйте настройки до обновления. Выпуск экспериментальный.

### Исправления
- «Проверить интерфейс MAX» теперь одновременно запускает диагностическую сессию.
  В отчёте есть запись старта/состояния службы даже без событий интерфейса MAX.
- Чтение экрана по таймеру 750 мс в течение 60 секунд, а не только по событиям MAX.
  Это пассивное чтение: реальная отправка выключается, кликов и ввода нет.
- Причина отказа конкретна: нет активного окна, заблокирован экран, не MAX,
  не найден заголовок, недоступны IDs, нет редактора сообщения или поля неоднозначны.
- Настройка замораживается при возвращении в CallShift; найденный образец можно
  сохранить 10 минут вместо 60 секунд. IDs/версия временного образца сохраняются
  локально для восстановления после пересоздания процесса. Номер и имя не сохраняются.
- Диагностика v3 содержит Profile capture и serviceConnected. Сырые resource IDs,
  тексты переписки, имена, телефоны и скриншоты по-прежнему не экспортируются.

### Как настроить
1. MAX: эксперимент → «Проверить интерфейс MAX».
2. Откройте **переписку с полем ввода сообщения**, не карточку с полем телефона
   и не список чатов. Подождите 2–3 секунды.
3. Вернитесь в CallShift → «Сохранить найденный профиль интерфейса».
4. Если отказ — сообщение покажет причину. «Посмотреть / скопировать отчёт» уже
   содержит результаты этой настройки; отдельно запускать диагностику не нужно.

Карточка контакта нужна позже для проверки получателя сценарием, а не для
сохранения профиля редактора чата. Проверки личности, +7/8, отсутствие ручной
привязки контактов и запреты повторов сохранены. Ограничения распознавания
структуры MAX не сняты: непроверяемый экран по-прежнему не принимается.

Unit-тесты покрывают причины отказа, неоднозначность, срок/версию образца и
отчёт без событий MAX. Реальная настройка на устройстве пользователя ещё
нуждается в проверке — не заявляем, что любой профиль теперь будет принят.
