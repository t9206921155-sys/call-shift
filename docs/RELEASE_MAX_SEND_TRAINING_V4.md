# CallShift 0.8.26-send-training-v4

## Что исправлено

В прошлой версии «доказательство отправки» действовало только 4 секунды после набора текста. Поиск стрелки пальцем занимает дольше — обучение снова падало с «Android не передал источник нажатия».

Теперь окно доказательства — **30 секунд**: набираете текст, спокойно жмёте стрелку, когда готовы. Плюс пережидается пересборка поля ввода сразу после отправки сообщения.

## Как обучить

1. «Автоответ MAX» → **«Обучить кнопку отправки MAX»** → «Начать обучение».
2. В MAX: безопасный чат (с самим собой или `+79206921155`).
3. Введите короткий текст. Дождитесь «Черновик распознан…».
4. Нажмите синюю стрелку — в течение 30 секунд, спокойно.
5. Результат появится сам; CallShift вернётся на свой экран.
6. «Проверить без отправки» → тестовая отправка.

## Безопасность

- Сохраняется только способ нажатия кнопки; получатель, чат, текст, координаты — никогда.
- Кнопка сохраняется только если: текст исчез (сообщение ушло) И в правой половине строки ровно одна кнопка (стрелка; скрепка исключена).
- Автонажатие — только та же версия MAX, профиль чата, получатель и текст; без повторов.
