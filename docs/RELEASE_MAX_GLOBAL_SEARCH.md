## CallShift 0.8.10-max-global-search — уже открытый поиск MAX

Экспериментальная версия, versionCode 42, прежний пакет и постоянная подпись.
Устанавливать поверх предыдущей версии. SIM → копии MAX и профиль чата сохраняются.

Скриншот пользователя показывает уже открытый общий поиск с полем
«Люди, чаты и сообщения», разделами «Недавно искали» и «Все контакты».
Прежний код эту подпись не распознавал и требовал выбранную вкладку «Чаты».
Это несовпадение исправлено; доступность элементов Accessibility на устройстве
пользователя по скриншоту не доказана, нужна проверка.

### Изменения
- Известная точная RU/EN подпись общего поиска добавлена в распознавание поля.
  Нормализуются регистр, переносы и неразрывные пробелы.
- Вход в уже открытый общий поиск не требует вкладки «Чаты». Вместо неё нужны:
  единственное видимое поле ввода, точная подпись в hint/description в верхней
  трети экрана, видимый раздел «Все контакты» или «Недавно искали», отсутствие
  редактора сообщения, поля телефона карточки и защищённых полей.
- Поля «Поиск» или «Поиск в чате» сами по себе глобальный поиск не подтверждают.
- Старый пользовательский запрос не стирается. Ввод выполняется только в пустое
  поле. Подсказка признаётся пустым текстом по прежнему явному флагу Android и
  совпадению text/hint, а не по совпадению с известной фразой без флага.
- После поиска прежние проверки личности и пустого черновика обязательны.
  Недавние контакты и результаты сообщений не считаются подтверждением получателя.
- Диагностика v7: GLOBAL_SEARCH и флаги Global search (число редакторов, число
  полей с глобальной подписью, наличие раздела и результат распознавания).

### Проверка без звонка
«Проверить каналы / тестовый ответ» → выбрать SIM и номер →
«MAX: тест навигации БЕЗ сообщения». Сохранённые маршруты/профиль не пересоздавать.
Можно оставить MAX на уже открытом общем поиске с пустым запросом. Не вмешиваться
в навигацию. При отказе скопировать отчёт v7 из «MAX: эксперимент».
Реальная отправка пока выключена. Тесты и сборка не заменяют проверку реального
ввода, результатов, карточки и возврата на устройстве пользователя.

Unit-тесты покрывают точные подписи, признаки общего поиска без вкладки, запрет
неизвестных/нескольких редакторов и защищённых полей, отличие подсказки от запроса,
ограниченный отчёт и его очистку.
