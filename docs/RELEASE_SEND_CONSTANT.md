# CallShift 0.8.43-send-constant

## MAX: кнопка отправки — константа, настройка переносится на новый телефон

- Кнопка отправки обучается один раз и больше не трогается: не сбрасывается при перезапусках и обновлениях CallShift.
- Перенос на новое устройство без переобучения: на старом телефоне «Автоответ MAX» → «Дополнительно» → «Скопировать настройку для нового телефона» (код попадёт в буфер); на новом — «Дополнительно» → «Вставить настройку с другого телефона».
- Код переносит: профиль чата, обученную кнопку отправки, привязку «какая SIM — какой MAX» и суточный лимит.
- Безопасность: после переноса реальная отправка всегда выключена — сначала проверка без отправки, затем включение. Если версия MAX на новом телефоне отличается, приложение честно потребует переприём профиля и переобучение — ничего не применяется вслепую.

## Раздел «Мессенджеры»

Карточки называют следующий шаг («Дальше: включите службу…», «обучите кнопку…»), тексты сжаты, подробности — под «Подробнее ▸» (появилось в 0.8.42).

## Алгоритм настройки MAX на новом телефоне

1. Установите MAX и войдите в нужный клон.
2. Установите CallShift, откройте «Мессенджеры» → MAX → «Настройка MAX».
3. Выберите SIM → укажите её клон MAX → перенесите настройку кодом (шаги выше).
4. Включите службу «CallShift — MAX» в спец. возможностях.
5. «Проверить без отправки» → затем разрешите реальную отправку.
