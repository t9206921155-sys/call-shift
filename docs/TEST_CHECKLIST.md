# TEST_CHECKLIST.md — приёмочные полевые тесты (ТЗ п. 14.3, критерии A-3/A-4)

**Важно:** эмулятор Android не поддерживает входящие GSM-вызовы и MMI/USSD (ТЗ п. 14.1).
Все пункты ниже выполняются **на реальном устройстве с реальной SIM** и вторым телефоном
для контрольных звонков. Результаты вносятся в протокол (раздел 6).

Обозначения: ☐ — не проверено, ✅ — пройдено, ❌ — провал, n/a — неприменимо.

## 3. Сетевая переадресация (S1, MMI)

| # | Проверка | Ожидание | Статус |
|---|---|---|---|
| 3.1 | `*21*<второй номер>#` через экран «Сетевая CF» | USSD-ответ оператора об успешной активации (или «статус неизвестен» без `ANSWER_PHONE_CALLS`) | ☐ |
| 3.2 | **Ключевая проверка:** телефон ВЫКЛЮЧЕН, звонок с третьего номера | Звонящий попадает на второй номер — переадресацию держит сеть, а не приложение | ☐ |
| 3.3 | `*#21#` | Получен фактический статус от оператора | ☐ |
| 3.4 | `##21#` | Переадресация снята, повторный звонок идёт на устройство | ☐ |
| 3.5 | `*61*<номер>**20#` | Переадресация по отсутствию ответа через 20 с: не отвечать 25 с → звонок уходит на цель | ☐ |
| 3.6 | `*67*<номер>#` | При занятой линии звонок уходит на цель | ☐ |
| 3.7 | `*62*<номер>#` | При выключенном телефоне звонок уходит на цель | ☐ |
| 3.8 | `##002#` | Сняты все условные переадресации | ☐ |
| 3.9 | Двухсимочное устройство: применить код к SIM2 | Переадресация включилась именно на SIM2 (`dumpsys telecom` / проверка звонком на SIM2) | ☐ |
| 3.10 | Номер цели в национальном формате (`0401234567`) | Приложение нормализует в E.164 (`+358401234567`) до подстановки в код (ТЗ FR-3.3) | ☐ |
| 3.11 | Ошибка оператора (код не поддерживается) | Понятное сообщение в UI и `errorCode` в журнале; приложение предлагает S2 (ТЗ R-3) | ☐ |
| 3.12 | Нет сети (авиарежим) при отправке MMI | `NO_NETWORK`, задача повторяется, desired-state сохранён (ТЗ E-07) | ☐ |
| 3.13 | «Режим паники» | За ≤ 10 с отправлены `##21#`/`##002#`/`##004#` на все SIM, все правила выключены, мастер-переключатель OFF | ☐ |
| 3.14 | После «Режима паники» — звонок с третьего номера | Идёт на устройство, переадресации нет | ☐ |

## 7. Команды для измерений

```bash
# тайминги и решения
adb logcat -s CallShift:D | grep screened

# батарея
adb shell dumpsys batterystats --charged fi.callshift.app | head -40

# память
adb shell dumpsys meminfo fi.callshift.app | head -20

# кто держит роли
adb shell cmd role get-role-holders --user 0 android.app.role.CALL_SCREENING

# SIM-аккаунты
adb shell cmd telecom list-phone-accounts

# состояние переадресации глазами сети
# набрать на устройстве: *#21#  *#62#  *#67#
```
