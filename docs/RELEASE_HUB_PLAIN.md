# CallShift 0.8.52-hub-plain

## «Мессенджеры» на максимально простых элементах

Экран раздела собран из самых простых платформенных элементов (обычные заголовки, строки и кнопки — те же классы, что в системных экранах Android), без сложных карточек и обёрток. Это последний из возможных источников «пустого экрана», который можно устранить без данных с устройства.

Также:

- Вверху раздела — оранжевая строка с версией и кнопка «Скопировать диагноз экрана»: копирует в буфер модель, Android, экран и состояние всех разделов. Пришлите текст, если раздел снова окажется пуст.
- На ГЛАВНОМ экране внизу теперь всегда видна версия сборки «CallShift X.Y (N)» — сразу понятно, установилась ли новая версия.
