# CallShift 0.8.48-hub-safe

## Раздел «Мессенджеры» больше не может быть пустым

- Если на конкретном устройстве что-то падает при открытии раздела — на экране появляется **точный текст ошибки** (и версия сборки), который можно переслать в чат поддержки. Пустой экран исключён.
- Если ошибка возникает при обновлении статусов — красная строка с текстом ошибки появляется внизу раздела, карточки продолжают работать.
- В подвале раздела всегда видна версия приложения: «CallShift 0.8.48 (80)» — чтобы точно знать, что установлена последняя сборка (частая причина «странностей» — обновление не встало или открыт старый экран из недавних).

Функционально — 0.8.47: Telegram без обучения кнопки (встроенное правило), настройка = два переключателя; MAX по мастеру.
