## CallShift 0.8.0-max-ui — экспериментальный выпуск

Подписан прежним ключом, пакет fi.callshift.app, versionCode 32. Устанавливается
поверх официальной версии. Это prerelease: НЕ подтверждён на реальном MAX.
Стабильной версией остаётся 0.7.5. Android обычно не допускает откат на меньший
versionCode без удаления данных: сохраните настройки до установки эксперимента.

### Что реализовано
Отдельный канал «MAX — эксперимент UI» и экран «MAX: эксперимент». По умолчанию
выключен, после настройки — проверка без ввода/нажатий. Системное разрешение
Accessibility выдаёт пользователь. Служба обрабатывает только ru.oneme.app.

Ограниченный детерминированный сценарий: открыть MAX → проверить текущий чат →
сравнить номер в шапке с номером звонящего → проверить пустое поле → ввести текст →
повторно проверить номер/текст → один раз нажать однозначную подписанную кнопку
«Отправить» рядом с полем. Поиск и переключение чатов НЕ реализованы: не нажимаем
по именам, координатам или непроверенным элементам. Доставка не подтверждается.

### Настройка
1. Главный экран → MAX: эксперимент. Прочитайте раскрытие доступа к интерфейсу.
2. Самостоятельно подключите службу в специальных возможностях Android.
3. Нажмите «Проверить интерфейс MAX», откройте личный чат с видимым ТЕЛЕФОНОМ в
   шапке toolbar, вернитесь и сохраните распознанный профиль. Если MAX показывает
   только имя, скрывает resource IDs или использует другую структуру — профиль
   НЕ будет принят. Это ограничение безопасности, не предложение обходить приватность.
4. В полном редакторе правила выберите только MAX UI и сначала сделайте новый
   тестовый звонок в режиме без отправки. Результат — в журнале MAX.
5. Только после проверки включайте реальную отправку отдельным подтверждением.

### Стоп-условия
Заблокированный/выключенный экран; другой чат/неизвестный номер; обновление MAX;
чужой черновик; неоднозначные элементы; отключённая служба/мастер; тайм-аут 15 с.
После переподключения службы реальная отправка выключается. Лимит 5 попыток за
скользящие 24 часа, резерв сохраняется до ввода; ошибки не возвращают его. Нет
автоповторов, очереди и запасной SMS. Ошибка после ввода может оставить черновик:
проверьте его вручную. Не включайте одновременно ручной MAX и MAX UI без необходимости.

Профиль хранит IDs элементов и версию MAX, не историю сообщений. Образец видимого
телефона живёт только в памяти при явной проверке, не экспортируется. Профиль и
разрешение на реальные нажатия не включены в резервные копии. Данные интерфейса
и ключи подписи не передаются в публичный релиз. Unit-тесты проверяют условия
отказа и нормализацию +7/8, но не подтверждают правильность реального интерфейса.

### Что ещё не завершено
Универсальная полностью фоновая отправка любому контакту MAX не реализована.
Для поддержки конкретной версии/экрана нужен тест на устройстве. Если профиль
не распознан, не включайте отправку и не пытайтесь обходить проверку получателя.
