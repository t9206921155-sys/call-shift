## CallShift 0.7.4

Подписанное обновление release-пакета fi.callshift.app, versionCode 30.
Устанавливается поверх официальной 0.7.3 без удаления приложения.

- Новые ручные ответы сохраняют канал и текст конкретной попытки в локальном журнале.
- «Открыть ответ» работает из журнала, в том числе при недоступном уведомлении.
- WhatsApp: чат по номеру с текстом. Telegram: ссылка разрешения номера и черновика;
  приватность/версия клиента может помешать открытию. MAX: текст передаётся в приложение,
  получателя выбираете вручную. Если приложение не принимает текст — понятная ошибка.
- Статус «Нужна ручная отправка»: открытие приложения не считается доставкой.
- Старые записи без снимка текста не восстанавливаются из изменённого правила.

Тексты черновиков остаются в приватном локальном журнале (до 500 событий),
не добавляются в CSV. «Очистить» удаляет историю. Пароль/ключ подписи не менялись.
Обновление не добавляет автоматическую отправку через обычные мессенджеры.
Реальная работа переходов зависит от установленного клиента, аккаунта и приватности;
на телефоне пока не проверена. Поддержка Telegram phone links:
https://core.telegram.org/api/links#phone-number-links
