# CallShift 0.8.24-send-training-v2

## Что исправлено в обучении кнопки отправки

На устройстве пользователя MAX не передаёт событие нажатия (как и при обучении карточки). Обучение 0.8.23 в этом случае заканчивалось молча или ошибкой «источник не передан». Теперь:

- **Сообщение доказывает нажатие.** Если после тапа текст исчез из поля (сообщение реально ушло), а в строке ввода есть ровно одна кнопка в правой половине — именно она сохраняется как кнопка отправки. Событие нажатия от Android больше не обязательно.
- **Каждый шаг показывает сообщение:** «Обучение запущено…» → «Черновик распознан. Нажмите синюю стрелку ОДИН раз» → «Проверяем, что сообщение ушло» → результат. Тишины больше нет.
- **Обучение вынесено на главный экран** «Автоответ MAX»: отдельная кнопка «Обучить кнопку отправки MAX» — искать в меню «Дополнительно» не нужно.

## Как обучить (один раз)

1. «Автоответ MAX» → **«Обучить кнопку отправки MAX»** → «Начать обучение».
2. В MAX откройте безопасный чат (с самим собой или `+79206921155`).
3. Введите любой короткий текст, дождитесь сообщения «Черновик распознан…».
4. Нажмите синюю стрелку один раз — сообщение уйдёт по-настоящему.
5. CallShift сам вернётся с результатом. Затем «Проверить без отправки» → тестовая отправка.

## Безопасность

- Сохраняется только способ нажатия кнопки (идентификатор/класс элемента, отпечаток строки ввода, версия MAX). Ни получателя, ни чата, ни текста, ни координат.
- Кнопка сохраняется только при железном доказательстве: текст исчез (сообщение отправлено) И кнопка определяется однозначно. Иначе — обучение не сохраняется и пишет причину.
- Автонажатие в реальных звонках — только при той же версии MAX, том же профиле чата, подтверждённом получателе и неизменном тексте. Без повторов и догадок.
- Обученную кнопку можно удалить: «Технические настройки MAX» → «Забыть обученную кнопку отправки».
