# CallShift 0.8.39-messenger-hub

## Все мессенджеры — в одном разделе

На главном экране новая кнопка **«Мессенджеры: MAX, Telegram, SMS»**. Внутри — по каждому каналу:

- **статус** (режим, обучение кнопки MAX, вход Telegram, использованные лимиты);
- **кнопки настройки** (MAX, аккаунт Telegram, правила SMS, защита SMS);
- **суточный лимит — одной кнопкой**, числом от 1 до 1000, действует сразу.

## Telegram: настраиваемый суточный лимит

Автоответы через аккаунт Telegram теперь ограничены так же, как MAX и SMS:

- лимит по умолчанию — 20 в сутки, меняется в разделе «Мессенджеры» (1–1000);
- резерв списывается перед самой отправкой (ошибки поиска получателя бюджет не тратят);
- при исчерпании лимита отправка останавливается с понятным сообщением, повторов нет;
- счётчик использованного показан в разделе.

SMS: лимит частей (уже существовавший) теперь тоже меняется из этого же раздела. MAX: лимит из 0.8.38 виден и меняется там же.

## Обновление

Установите 0.8.39 поверх. Обучение, лимиты и аккаунты сохраняются.
