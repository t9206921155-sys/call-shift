# CallShift 0.8.37-send-proof

## Что изменилось

Сообщение отправлялось и доставлялось, а результат в отчёте и на экране говорил «доставка не подтверждена». Теперь после нажатия CallShift в течение 6 секунд читает только поле ввода (ничего не нажимает, повторов нет):

- текст исчез из поля → результат: **«Сообщение предположительно отправлено»** (UI_SENT_LOCAL) в журнале, на экране и в отчёте;
- текст остался → «вероятно, сообщение не ушло. Проверьте чат»;
- экран ушёл из MAX → нейтральный результат.

Доставку (галочку «прочитано/доставлено» внутри MAX) по-прежнему подтверждает только получатель — CallShift не читает содержимое переписки.

## Обновление

Установите 0.8.37 поверх. Обучение и настройки сохраняются.
