# CallShift 0.8.46-tg-train-auto

## Обучение кнопки Telegram: автопилот

Раньше обучение требовало вручную открыть Telegram и чат — отсюда «не открывает, текст не вводит, висит». Теперь после нажатия «Обучить кнопку отправки Telegram» CallShift всё делает сам:

1. Открывает Telegram.
2. Сам находит и открывает чат «Избранное» (Saved Messages) — безопасный чат с самим собой.
3. Сам вводит тестовый текст «Тест обучения CallShift» (будит поле-заглушку, если оно свёрнуто).
4. Вам остаётся ОДНО нажатие кнопки отправки. Текст уйдёт вам же в «Избранное».

Если автоввод не прошёл (редкая сборка Telegram) — подсказка: введите текст вручную, обучение продолжится. Если «Избранное» не нашлось (другой язык интерфейса) — откройте любой безопасный чат вручную, дальше всё так же.

Сохранение кнопки прежнее: по событию нажатия, а если Android не передал событие — по исчезновению текста (кнопка, замеченная одной у поля ввода, как жест). Ничего не сохраняется при неоднозначности.
