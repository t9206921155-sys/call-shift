# CallShift 0.8.25-send-training-v3

## Что исправлено

На экране обучения пришла ошибка «кнопку возле поля нельзя определить однозначно». Причина: в строке ввода MAX две кнопки — скрепка (слева) и синяя стрелка (справа). Прошлая версия требовала, чтобы кнопка была одна во всём ряду.

Теперь кнопка отправки ищется только в **правой половине строки ввода**, где есть только стрелка. Скрепка и другие левые кнопки исключаются. Обучение проходит и на этом MAX.

## Как обучить (без изменений)

1. «Автоответ MAX» → **«Обучить кнопку отправки MAX»** → «Начать обучение».
2. В MAX откройте безопасный чат (с самим собой или `+79206921155`), введите короткий текст.
3. Дождитесь «Черновик распознан. Нажмите синюю стрелку отправки ОДИН раз».
4. Нажмите стрелку. Сообщение уйдёт; CallShift сохранит кнопку и сам вернётся.
5. Затем «Проверить без отправки» → тестовая отправка.

## Безопасность

- Сохраняется только способ нажатия кнопки; получатель, чат, текст и координаты не хранятся.
- Кнопка сохраняется только при доказательстве: текст исчез (сообщение отправлено) И в правой половине ряда ровно одна кнопка.
- Автонажатие — при той же версии MAX, профиле чата, получателе и тексте. Без повторов.
- Удалить обучение: «Технические настройки MAX» → «Забыть обученную кнопку отправки».
