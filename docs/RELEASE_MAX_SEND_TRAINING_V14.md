# CallShift 0.8.36-send-training-v14

## Разрыв цикла «черновик есть → проверка не идёт»

Прошлые остановленные попытки оставляли в чате черновик «Тестовый ответ CallShift». Каждая новая проверка честно останавливалась на нём (DRAFT_NOT_EMPTY), и до реальной отправки дело никогда не доходило.

Теперь черновик, который **байт-в-байт совпадает с тестовым текстом этой проверки**, очищается автоматически, и сценарий продолжается. Это остаток самой CallShift, не ваше сообщение. Любой другой черновик по-прежнему не трогается — проверка остановится, и его нужно удалить вручную.

## Действия

1. Установите 0.8.36 поверх.
2. «Проверить без отправки» — остаток будет очищен, проверка пройдёт.
3. Разрешите реальные ответы и запустите тестовую отправку — сообщение уйдёт (обученная кнопка уже сохранена).
