# CallShift 0.6.6-test — цельная проверка «SIM → сброс → SMS»

## Что действительно реализовано

1. Привязка правила к публичному ID конкретной SIM; чужая/неопределённая SIM
   не подставляется вместо выбранной. Старые ID принимаются только однозначно.
2. Отдельный автоответчик проверяется раньше правил. Диагностика и проверка
   правила предупреждают об этом и об исключении повторных звонков.
3. SMS автоматически передаётся с SIM входящего вызова. Ошибка определения
   SIM означает отказ отправки, не платную отправку с другой карты.
4. Для каждой части SMS запрашиваются SENT и DELIVERY callbacks Android.
5. Одна попытка SMS — одна обновляемая карточка, без отдельной вечной карточки
   «ждём». Экран журнала обновляется при изменении статуса.
6. Метаданные попытки и результаты частей сохраняются на устройстве. Явный
   private BroadcastReceiver принимает поздние отчёты после пересоздания процесса.
7. WorkManager помечает отсутствие полного SENT через 2 минуты как UNKNOWN,
   отсутствие полного DELIVERY через 24 часа — как «доставка не подтверждена».
   Это минимальные задержки, Android/Doze может отложить выполнение.
   Поздний достоверный отчёт обновляет статус, ложного успеха или автоповтора нет.
8. Быстрый ручной SMS-ответ использует тот же механизм отслеживания.
9. «Статус» → «Проверить SMS с выбранной SIM»: реальная тестовая SMS, только
   после выбора SIM, номера и явного подтверждения стоимости. Звонить для этого
   не нужно. Тест не отключает и не изменяет ваши правила.

## Настройка один раз

- Установить тестовый APK. Он имеет отдельный packageId `.debug`: роль перехвата
  и разрешения нужно выдать тестовой копии, а не старому установленному приложению.
- В «Статусе» запросить разрешения. Для каждой карты видно, определена ли она для SMS.
- Для проверки правила отключить отдельный автоответчик (иначе он имеет приоритет).
- Выбрать рабочую SIM, «все звонки», действие «Сбросить», канал SMS, непустой текст.
- Если нужен сброс каждого звонка: отключить исключение «Повторный звонок».
- Отправки по правилу ограничены одной попыткой на номер/канал за 30 минут.
  При неизвестном/частичном результате нет автоматического повторения платной SMS.

## Значение карточек

| Статус | Что известно |
|---|---|
| Ожидание отправки | Задание передано Android, полного подтверждения ещё нет |
| SMS отправлено | Есть подтверждение отправки; доставка всех частей ещё не доказана |
| SMS доставлена | Отчёты подтверждают доставку всех частей; не означает прочтение |
| Ошибка отправки | Отказ API/Android или ошибка части; указаны коды/счётчики |
| Ошибка доставки | Оператор сообщил финальный отрицательный статус |
| Результат неизвестен | Не получены все подтверждения отправки |
| Доставка не подтверждена | За 24 часа не получены все отчёты доставки; это не доказательство недоставки |

Если получатель не видит SMS, статус «отправлено» НЕ доказывает получение.
Оператор/прошивка может не поддерживать отчёты. Приложение не может гарантировать
доставку в чужую сеть или отменить фильтрацию у получателя.

## Мессенджеры — явные границы

В этой сборке только SMS автоматическая. WhatsApp — переход по номеру с текстом;
Telegram/MAX/другие — ручной выбор приложения и чата. Все они явно обозначены
«РУЧНАЯ отправка», не заменяются платной SMS и не считаются доставленными.
Автоматический MAX требует отдельной авторизованной интеграции бота и связи
номера с user_id/chat_id. Это не реализовано и не обещается этой сборкой.

## Проверки

Unit-тесты покрывают состояния отправки/доставки, части, повторы, неправильный
порядок callbacks, таймауты, позднюю доставку, сериализацию/восстановление,
ошибки/невалидные индексы, отображение/счётчики, каналы, номера, правила и SIM.
CI компилирует и тестирует код, но не звонит в сеть оператора.

Полевое принятие: тестовая SMS на свой второй телефон; затем входящий на рабочую
SIM (сброс и SMS), на личную (обычный звонок), повторный вызов (без SMS-дубля),
режим без сети, заблокированный экран и поздний отчёт после закрытия приложения.
Физический двухсимочный телефон и сеть оператора в среде разработки недоступны.

Состояние хранится для последних 500 SMS-попыток; текст SMS в хранилище статусов
не сохраняется. Принудительная остановка/удаление приложения и сброс данных
могут прервать получение отчётов — это не трактуется как доставка.
