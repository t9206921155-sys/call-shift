## CallShift 0.8.8-max-navigation — переход к общему поиску

Эксперимент, versionCode 40. Тот же пакет и постоянная подпись, установка поверх
предыдущей версии без удаления. Маршруты SIM и профиль интерфейса сохраняются.

### Изменения
- Если текущий распознанный чат не подходит, после проверки пустого поля сообщения
  можно один раз выполнить «Назад». Это также запасной путь, когда карточку именно
  текущего, ещё не выбранного поиском чата нельзя открыть.
- После возврата — максимум 4 секунды на распознавание общего списка: выбранный
  элемент «Чаты» / Chats (или его ближайший неколлекционный родитель), видимая
  коллекция, отсутствие редактора сообщения/подписи телефона и посторонних полей.
  По одной лупе или заголовку «Чаты» список не признаётся: это может быть имя чата.
- После подтверждения списка — существующий поиск по +7/8, затем имени из контактов
  Android при наличии разрешения. Имя по-прежнему лишь кандидат: перед сообщением
  обязательны проверка телефона и пустого поля. Поиск внутри текущего чата больше
  не принимается за общий поиск.
- Если Назад только скрыл клавиатуру, окно изменилось, список не распознан или MAX
  ушёл с экрана — отправки нет. Повторные нажатия Назад для подбора экрана запрещены.
- При найденном поиском контакте ошибка открытия карточки по-прежнему блокирует
  отправку, не обходится навигацией. Если карточка не открывается вообще, эта
  версия не объявляет проблему решённой.
- Диагностика v6: добавлены CHAT_LIST_BACK / CHAT_LIST, коды CHAT_LIST_UNCONFIRMED,
  CHAT_CHANGED_BEFORE_BACK, CHAT_LIST_BACK_FAILED, CHAT_LIST_BACK_ALREADY_USED.

Дополнительно видимое защищённое поле останавливает сценарий до навигации;
оно не игнорируется при распознавании списка. Повторная проверка есть перед
открытием карточки, возвратом и вводом сообщения. Защиту MAX не обходим.

### Проверка
Оставьте сохранённые маршруты и профиль. «Диагностика следующего звонка» → тестовый
звонок на настроенную SIM. Телефон разблокирован, в MAX нет черновика; для проверки
нового пути можно оставить другой личный чат. Сценарий может выбрать копию, выйти
из этого чата, открыть общий поиск и карточку результата. Это реальные действия
навигации, но текст сообщения и кнопка отправки в диагностике не используются.

При отказе скопируйте отчёт v6. Если глобальный список этой версии MAX не выставляет
выбранную вкладку Accessibility, будет CHAT_LIST_UNCONFIRMED, а не поиск наугад.
До успешной проверки всей цепочки реальную отправку не включать.

Тесты покрывают предикат списка, отказ для чата/карточки/неизвестного редактора,
неоднозначные поля и код отчёта. Android-переходы на устройстве пользователя пока
не проверены. Выбор копии ранее подтверждён его отчётом; поиск и отправка — нет.
