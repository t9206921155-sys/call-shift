# CallShift 0.8.51-hub-diag

## Диагностика вместо догадок

Если раздел «Мессенджеры» на устройстве пуст:

- В самом верху всегда видна (или не видна) оранжевая строка с версией сборки — это маркер рендера.
- Кнопка «Скопировать диагноз экрана» кладёт в буфер обмена техническую сводку: версия, модель, Android, экран, ночная тема, видимость и высота каждой карточки, текст ошибок. Пришлите её в чат — правка будет прицельной.
- Через 1,5 секунды после открытия, если карточки не отрисовались, верхняя строка сама предупредит: «Карточки не отображаются на этом устройстве».

Функционально — 0.8.50: карточки MAX / Telegram / SMS, «Дальше: …», лимиты, Telegram без обучения кнопки.
