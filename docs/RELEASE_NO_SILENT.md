# CallShift 0.8.49-no-silent

## Больше никаких «висит»: каждая попытка заканчивается записью в журнале

Найдена главная причина «не открывает и висит»: если служба «CallShift — Telegram (имитация касаний)» выключена (или её отключил Android — батарея, перезагрузка), попытка обрывалась **молча**: Telegram не открывался, в журнале тишина.

Теперь:

- Выключенная служба → немедленная запись в журнале: «Служба не включена… Включите её: Настройки → Спец. возможности. Сообщение не отправлено; повторов нет». Раньше попытка терялась без следа.
- Если Telegram не даёт ввести текст — CallShift тапает по контейнеру поля и пробует ещё раз, прежде чем отказать с точной причиной.
- Любой сценарий завершается записью в журнале не позднее 45 секунд.

## Проверка на телефоне (1 минута)

1. Android: Настройки → Спец. возможности → «CallShift — Telegram (имитация касаний)» = ВКЛ (это переключатель №1 из двух).
2. CallShift → «Мессенджеры» → Telegram: «Дальше: …» не должно предлагать включить службу.
3. Тестовый звонок/тест канала → смотрите уведомления: «открываем приложение» → «ищем чат по номеру» → «вводим текст» → «нажимаем кнопку отправки».
