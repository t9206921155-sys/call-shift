# CallShift 0.8.34-send-training-v12

## Исправление — последнее

Кнопка отправки успешно обучилась (в отчёте: Send learning=SAVED, ANCHORED_SEND_GESTURE). Оставалась одна преграда: финальная проверка перед нажатием требовала у стрелки признак «кликабельная», которого в этой версии MAX нет — нажатие блокировалось («перед отправкой изменились…»).

Теперь для обученной жестовой кнопки требование кликабельности снято: перед нажатием проверяется только свежесть (та же кнопка, тот же экран, получатель, текст) — а само нажатие выполняется настоящим касанием по свежим координатам стрелки.

## Что делать

Обучение у вас уже сохранено — повторять НЕ нужно. Просто:

1. Установите 0.8.34 поверх.
2. Нажмите «Проверить без отправки» — должно дойти до нажатия.
3. Затем тестовая отправка.

Если обучение вдруг слетит (например, после обновления MAX) — «Обучить кнопку отправки MAX» заново, один раз.
