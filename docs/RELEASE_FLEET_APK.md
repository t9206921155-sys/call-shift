# CallShift 0.8.53-fleet-apk

## Почему APK «повреждён» и что сделано

Полный APK вырос до ~116 МБ (встроенные библиотеки Telegram для всех архитектур). На телефоне браузер часто не докачивает такой файл до конца, а обрезанный APK Android называет «пакет недействителен (повреждён)».

Теперь в каждом релизе два файла:

- **CallShift-0.8.53-fleet-apk-arm64.apk (~30–40 МБ)** — для обычных современных телефонов. Качайте его.
- CallShift-0.8.53-fleet-apk.apk (~116 МБ) — универсальный (старые 32-битные телефоны, эмуляторы).

Оба подписаны одним постоянным ключом, взаимозаменяемы (можно ставить один вместо другого поверх).

Если установка всё же скажет «пакет повреждён» — файл не докачался: удалите скачанное, скачайте заново и сравните размер файла с указанным в SHA256SUMS.txt релиза.
