# CallShift 0.8.29-send-training-v7

## Исправление

Самостоятельный ввод текста при обучении не доходил до поля: CallShift делал одну попытку и считал дело сделанным. Теперь ввод проверяется по факту: фокус в поле → ввод → контроль, что текст реально виден, до 5 попыток. «Текст введён» появляется только когда текст действительно стоит в поле. Если всё же не получилось — приложение прямо попросит ввести любой текст вручную, и обучение продолжится.

Порядок прежний:

1. «Обучить кнопку отправки MAX» → «Начать обучение».
2. В MAX откройте безопасный чат (с самим собой или `+79206921155`).
3. Дождитесь «Текст введён. Нажмите синюю стрелку ОДИН раз».
4. Нажмите стрелку. → «Кнопка отправки распознана и сохранена».
5. «Проверить без отправки» → тестовая отправка.

Если возвратило в CallShift раньше времени — просто вернитесь в MAX: обучение продолжает работать (об этом напомнит экран CallShift).
