# CallShift 0.8.50-hub-xml

## «Мессенджеры» переписаны на классическую разметку

Экран, который у части устройств оставался пустым, собран заново тем же способом, что и все проверенные экраны приложения (стандартная XML-разметка + view binding вместо программного создания элементов). Это убирает сам класс сбоя, при котором фон рисовался, а содержимое — нет.

Всё остальное — как в 0.8.49: карточки MAX / Telegram / SMS с точным «Дальше: …», лимиты 1–1000, Telegram без обучения кнопки, версия сборки в подвале экрана, любая ошибка показывается текстом, а не пустотой.

Если раздел всё же не откроется — на экране будет текст ошибки с версией; перешлите его целиком.
