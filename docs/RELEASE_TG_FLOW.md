# CallShift 0.8.45-tg-flow

## Сценарий Telegram больше не висит молча

Чинит «не открывает, текст не вводит, сценарий висит»:

- **Telegram открылся в последнем чате.** Telegram часто восстанавливает последний открытый чат — раньше это означало отказ. Теперь CallShift сам один раз возвращает его к списку чатов кнопкой «назад» и продолжает поиск номера.
- **Поле ввода по фокусу.** На экране поиска Telegram полей бывает несколько — теперь ввод идёт в сфокусированное, а не в «первое попавшееся» или ни в какое.
- **Кнопка поиска.** Нажимается любой узнанный элемент поиска: сама кнопка, её кликабельный предок или дочерняя иконка.
- **Прогресс видно.** На каждом шаге — короткое уведомление: «открываем приложение» → «ищем поиск» → «ищем чат по номеру» → «вводим текст» → «нажимаем кнопку отправки». Тишины больше не будет: каждый сценарий завершается записью в журнале не позднее 45 секунд.
