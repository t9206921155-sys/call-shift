# CallShift 0.8.30-send-training-v8

## Исправление

Отчёт с устройства показал NO_CANDIDATES: текст в поле есть, а сканер не находит ни одной кнопки рядом — в этой версии MAX стрелка либо не помечена как «кликабельная», либо лежит внутри прокручиваемого контейнера, который сканер исключал.

Теперь кандидаты ищутся по принадлежности к контейнеру поля ввода (общий близкий предок) и вертикальной полосе поля. Кликабельность не требуется: реальное нажатие и так выполняется касанием по свежим координатам обученной кнопки. Список сообщений по-прежнему исключён.

## Порядок обучения (не изменился)

1. «Обучить кнопку отправки MAX» → «Начать обучение».
2. В MAX откройте безопасный чат (с самим собой или `+79206921155`).
3. Дождитесь «Текст введён. Нажмите синюю стрелку ОДИН раз».
4. Нажмите стрелку → «Кнопка отправки распознана и сохранена».
5. «Проверить без отправки» → тестовая отправка.
