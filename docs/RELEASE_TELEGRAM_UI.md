# CallShift 0.8.41-telegram-ui

## Telegram отвечает сам — имитацией касаний, как MAX

Новый режим: CallShift сам открывает приложение Telegram, находит чат по номеру звонившего, вводит текст ответа из правила и нажимает кнопку отправки. Аккаунт Telegram в CallShift подключать НЕ нужно — используется Telegram, уже установленный и залогиненный на телефоне.

### Как включить (5 шагов)

1. Обновите приложение. Настройки сохраняются.
2. Android: Настройки → Спец. возможности → включите службу «CallShift — Telegram (имитация касаний)».
3. CallShift → «Мессенджеры» → Telegram → «Аккаунт Telegram: вход и автоотправка» → раздел «Отправка имитацией касаний (как в MAX)».
4. Включите «Отправлять имитацией касаний вместо TDLib» (потребуется служба из шага 2).
5. Нажмите «Обучить кнопку отправки Telegram»: откройте безопасный чат (например «Избранное») — CallShift сам введёт тестовый текст «Тест обучения CallShift», вам нужно нажать кнопку отправки ОДИН раз. Затем включите «Разрешить реальную отправку».

В правиле звонка канал «Telegram — автоматически (мой аккаунт)» менять не нужно: при включённой имитации отправка идёт через приложение, при выключенной — прежним способом.

### Безопасность — тот же принцип, что в MAX

- Номер подтверждается: чат открывается только если Telegram вернул ровно один результат с этим номером («+7» и «8» равнозначны). Несколько совпадений — отказ.
- По умолчанию режим «проверка без отправки»: сценарий доходит до кнопки и останавливается, реальная отправка включается отдельным переключателем.
- Чужие черновики не трогаются: если в поле уже есть текст, не совпадающий с текстом CallShift, — отказ. Остаток собственного тестового текста очищается автоматически.
- Одна попытка, без повторов и координат: нажатие — по сохранённой форме кнопки; чат, контакт и текст не хранятся.
- Итог честный: «текст исчез из поля — предположительно отправлено»; доставку подтверждает только получатель.
- Суточный лимит Telegram (по умолчанию 20, меняется в «Мессенджерах» до 1000) действует и в этом режиме; резерв списывается до открытия Telegram.
- Telegram обновился — кнопка требует повторного обучения, отправка блокируется.
