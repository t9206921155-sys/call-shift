# CallShift 0.8.55-messenger-switches

## Автоответы MAX и Telegram — явные переключатели

- **MAX:** на экране «Автоответ MAX» появился общий переключатель реальных автоответов. Включить его можно после завершённой проверки без отправки; выключение сразу закрывает новые сценарии и сохраняет правила, маршруты SIM и обучение.
- **Telegram:** один переключатель разрешает/останавливает автоответы выбранным способом — TDLib или имитацией касаний. Переключение способа сбрасывает разрешение, чтобы новая конфигурация не начала отправлять сообщения без отдельного включения.
- **Обучение кнопки отправки** оставлено запасным вариантом: для Telegram — внизу настроек, для MAX — в меню «Дополнительно». Обычно применяется автоматическое распознавание; повторное обучение нужно, если обновление мессенджера изменило его интерфейс.
- При выключенной имитации Telegram CallShift не запускает пробную навигацию и не оставляет черновик.

Тестовая реальная отправка по-прежнему выполняется только после явного подтверждения. Неизвестный результат не повторяется автоматически.
