## CallShift 0.8.9-channel-tests — тестовый ответ прямо в приложении

Экспериментальная версия, versionCode 41. Тот же пакет и постоянная подпись;
обновление без удаления. Настроенные SIM → экземпляры MAX сохраняются.

### Единый экран
На главной и в настройках автоответчика: «Проверить каналы / тестовый ответ».
- Явный выбор активной SIM, канала, номера (+7/8 эквивалентны) и текста до 201 символа.
- Проверка всех каналов без отправки: разрешения, доступность SIM для SMS,
  установленный MAX, служба/профиль/режим MAX, маршрут выбранной SIM и его тест,
  настройки/текущий статус Telegram API, наличие клиентов ручных каналов.
  Это локальная проверка, не гарантия сети, поиска человека или доставки.
- «Настроить SIM → основной MAX / копия» открывает существующие настройки.
  Для настоящего звонка используется SIM из контекста звонка, для теста — явно
  выбранная SIM. Она не подставляется автоматически при неизвестном аккаунте.
- «MAX: тест навигации БЕЗ сообщения» запускает существующую диагностику MAX,
  выключает реальную отправку, но может выбрать копию, искать и открывать карточку.
  Активный сценарий этим экраном не прерывается: новый тест блокируется.
- Тест выбранного канала требует отдельного подтверждения с номером, текстом и SIM.
  SMS — реальная тарифицируемая отправка через выбранную SIM; Telegram API — через
  уже подключённый аккаунт; MAX UI — через существующий маршрут SIM и только при
  отдельно разрешённой реальной отправке. Проверки получателя/лимиты сохранены.
- WhatsApp, Telegram ручной, MAX ручной и «Другой» только готовят ответ. На экране
  есть кнопка открытия подготовленного ответа; человек проверяет аккаунт и нажимает
  отправку самостоятельно. SIM не переключает аккаунты этих мессенджеров.
- Результат обновляется по журналу, включая последующие SMS/Telegram подтверждения,
  отказ MAX и проверку без сообщения. Запрос, нажатие и доставка не смешиваются.
  Тесты отмечены «Тест из приложения» и direction=TEST, не как реальные звонки.

### Ограничения и защита
Это проверка канала отправки, НЕ проверка условий правила, сброса звонка или
разрешения Android на запуск из фона. Правила и настройки автоответчика не меняются.
Отправка идёт через существующий диспетчер ответов, не через обход лимитов.
Тест применяет минутную паузу по каналу/получателю с общей историей попыток,
обычные лимиты SMS-частей/MAX и отсутствие автоматических повторов/резервной SMS.
История не очищается; соседний тест может попасть под паузу. MAX сейчас имеет
общую паузу для номера на разных SIM. Для платной SMS явно показано предупреждение.
Поворот/возврат на экран не запускают тест повторно. Разрешения сами не выдаются.

Маршрутизация SIM → MAX, поиск/карточка и отправка остаются экспериментальными.
На телефоне пользователя выбор копии подтверждался ранее, полная цепочка нет.
Новый экран не означает, что все мессенджеры получили автоматическую отправку.

Тесты домена: обязательная активная SIM, полный телефон, непустой ограниченный текст,
один канал на попытку, пауза, +7/8 и маркировка теста отдельно от входящего звонка.
Android UI/реальная отправка тестов на устройстве пользователя пока не проверены.
