# CallShift — памятка команд и действий

Короткая шпаргалка: как установить, выдать роль, добавить правило и проверить, что всё работает.

---

## 0. Сначала проверьте версию

Главный экран без кнопки **«Выдать роль перехвата (Call Screening)»** или «Телефон» без цифровой
клавиатуры (одна огромная кнопка «Позвонить») означают, что установлена **старая сборка (≤ 0.2.0)**.
Удалите её и поставьте свежую:

| Сборка | Package | Где взять |
|---|---|---|
| 0.2.2-m2 debug (с SMS-автоответом) | `fi.callshift.app.debug` | PR #1 → Checks → CallShift CI → Artifacts → `CallShift-debug-apk` |
| 0.2.1-m2 release | `fi.callshift.app` | `apks/CallShift-v0.2.1-m2-standard-release.apk` |

> Debug- и release-сборки — **разные приложения** (разный package). Роль перехвата может быть
> только у одного из них. В командах ниже подставляйте свой package в `PKG`.

## 1. Настройка БЕЗ компьютера (на телефоне)

1. Установить APK → открыть → принять дисклеймер.
2. **Выдать роль перехвата** — кнопка на главном экране или «Статус» → «Выдать роль».
   Если окно не появилось:
   *Настройки → Приложения → Приложения по умолчанию → «Определение номера и спам-фильтр»* → CallShift.
   - Oppo / Realme / OnePlus (ColorOS): *Настройки → Приложения → Приложения по умолчанию →
     «Приложение для звонков / Caller ID»*.
   - Xiaomi: *Настройки → Приложения → Управление приложениями → ⋮ → Приложения по умолчанию*.
3. **Android 13+ «Ограниченная настройка»**: *Настройки → Приложения → CallShift → ⋮ (правый
   верхний угол) → «Разрешить ограниченные настройки»*, затем повторить шаг 2.
   Если ⋮ нет — сначала попробуйте выдать роль (появится блокировка), после этого пункт появится.
4. **Разрешения** — кнопка «Выдать разрешения» на главном экране (телефон, контакты, журнал
   вызовов, SMS, уведомления).
5. **Батарея / автозапуск**:
   - Oppo/Realme: *Настройки → Батарея → CallShift → Разрешить фоновую активность*, *Автозапуск = ВКЛ*.
   - Xiaomi: *Автозапуск = ВКЛ*, *Контроль активности → Нет ограничений*.
   - Samsung: *Батарея → CallShift → Не ограничено*.
6. Главный экран: статус должен стать **«АКТИВЕН · Профиль A (Call Screening)»**, переключатель вверху — ВКЛ.

## 2. Настройка С компьютером (ADB)

Подготовка: *Настройки → О телефоне → 7 раз нажать «Номер сборки»* → *Для разработчиков →
Отладка по USB = ВКЛ*. Подключить кабель, подтвердить отпечаток ключа на телефоне.

```bash
PKG=fi.callshift.app            # для debug-сборки: PKG=fi.callshift.app.debug

adb devices                      # устройство должно быть в статусе "device"

# Установка (-g сразу выдаёт runtime-разрешения)
adb install -r -t -g CallShift.apk

# Всё одной командой (роль + разрешения + батарея):
PKG=$PKG bash scripts/setup_device.sh CallShift.apk
```

### Роли

```bash
# Выдать роль перехвата (обязательно)
adb shell cmd role add-role-holder --user 0 android.app.role.CALL_SCREENING $PKG
# Сделать основным «Телефоном» (профиль B, необязательно)
adb shell cmd role add-role-holder --user 0 android.app.role.DIALER $PKG

# Проверить, у кого роль
adb shell cmd role get-role-holders --user 0 android.app.role.CALL_SCREENING
adb shell cmd role get-role-holders --user 0 android.app.role.DIALER

# Снять роль
adb shell cmd role remove-role-holder --user 0 android.app.role.CALL_SCREENING $PKG
```

### Разрешения

```bash
for p in READ_PHONE_STATE READ_PHONE_NUMBERS CALL_PHONE ANSWER_PHONE_CALLS \
         READ_CALL_LOG WRITE_CALL_LOG READ_CONTACTS SEND_SMS POST_NOTIFICATIONS; do
  adb shell pm grant $PKG android.permission.$p
done

# Снять блокировку «ограниченных настроек» (Android 13+)
adb shell appops set $PKG ACCESS_RESTRICTED_SETTINGS allow

# Исключить из оптимизации батареи
adb shell dumpsys deviceidle whitelist +$PKG

# Проверить выданные разрешения
adb shell dumpsys package $PKG | grep -A 20 "runtime permissions"
```

### Логи и диагностика

```bash
adb logcat -s CallShift:D                      # живой лог: каждый звонок → строка "screened ..."
adb logcat -c                                  # очистить лог перед тестом
adb shell am force-stop $PKG                   # перезапуск приложения
adb shell pm clear $PKG                        # СБРОС всех данных и правил (осторожно)
```

### Удаление

```bash
bash scripts/uninstall_cleanup.sh             # снимет MMI-переадресации, роли, удалит APK
```

## 3. Как добавить правило

Главный экран → **«+»** (зелёная кнопка справа внизу) → заполнить → **«Сохранить»**.
Правило появится в списке «Правила переадресации». Кнопка **«Тест»** проверяет правило на номере
без реального звонка.

| Поле | Что писать |
|---|---|
| Название | любое |
| Приоритет | меньше число = проверяется раньше (например 10) |
| Маска номера | `+7999*` — все номера на +7999; `*` — любой; пусто — без условия по номеру |
| В контактах / Скрытый номер | дополнительные условия |
| Куда направить звонок | таблица ниже |
| Что сделать со звонком | таблица ниже |
| Номер, куда переадресовывать | появляется только для переадресации/перезвона, формат `+7…` |
| SMS-автоответ | текст SMS звонящему (только если звонок сбрасывается) |

**«Куда направить звонок»** (стратегия):

| В приложении | Что делает |
|---|---|
| Ничего не делать | Никуда не переадресовывает, со звонком — только то, что выбрано ниже. Для простого сброса |
| Сбросить и перезвонить на другой номер | Сброс + телефон сам звонит на указанный номер (новый звонок с вашей SIM) |
| Переадресация через оператора | Включает `*21*номер#` у оператора — звонящий попадает прямо на номер. Действует на все звонки до отключения |
| Только уведомить | Уведомление о звонке с названием правила |
| SIP-мост | Пока не работает |

**«Что сделать со звонком на этом телефоне»** (вердикт):

| В приложении | Что делает |
|---|---|
| Сбросить | Отклонить сразу |
| Сбросить и записать в пропущенные | Отклонить, оставить в пропущенных (не на всех телефонах) |
| Без звука | Не звонит, но звонок виден на экране |
| Пропустить | Звонит как обычно |

### Готовые примеры

| Задача | Маска | Условие | Куда направить | Что сделать со звонком | Номер / SMS |
|---|---|---|---|---|---|
| Сбрасывать скрытые номера | — | Скрытый номер | Ничего не делать | Сбросить | — |
| Сбрасывать всех + SMS | `*` | — | Ничего не делать | Сбросить | SMS: «Не могу говорить, напишите» |
| Звонки с +7999… — перезвонить на другой номер | `+7999*` | — | Сбросить и перезвонить | Сбросить | `+79001234567` |
| Уведомлять о звонках из контактов | — | В контактах | Только уведомить | Пропустить | — |

> Правила срабатывают **только если**: у приложения есть роль перехвата, главный переключатель
> включён, правило включено (переключатель в карточке правила).

## 4. Коды оператора (MMI) — вручную из «Телефона»

| Код | Действие |
|---|---|
| `*21*+79001234567#` | безусловная переадресация всех звонков |
| `*61*+79001234567**20#` | если не ответил за 20 с |
| `*62*+79001234567#` | если недоступен |
| `*67*+79001234567#` | если занято |
| `*#21#` | проверить статус переадресации |
| `##21#` | отключить безусловную |
| `##002#` | **отключить ВСЕ переадресации** (то же делает кнопка «Паника») |

## 5. Если не работает — по порядку

| Симптом | Что делать |
|---|---|
| «Внимание: нет роли перехвата» | Раздел 1, шаги 2–3, или `adb shell cmd role add-role-holder …` |
| Нет кнопки «Выдать роль», нет клавиатуры в «Телефоне» | Старая сборка — раздел 0 |
| Окно выдачи роли не появляется | Отклонили 2 раза → выдайте через Настройки или ADB |
| Правило не сохраняется | Маска: только `+`, цифры, `*`, `?` (без пробелов, скобок, дефисов; не более двух `*`); обновите сборку |
| Отмечены и «контакты», и «скрытые» | Так нельзя — условия взаимоисключающие, оставьте одно |
| Правило для скрытых номеров не срабатывает | Android не передаёт скрытые номера фильтру; нужно сделать CallShift основным «Телефоном» |
| Правило есть, но звонок не сбрасывается | Роль, главный переключатель, приоритет; смотреть «Журнал» и `adb logcat -s CallShift:D` |
| После перезагрузки перестаёт работать | Автозапуск и батарея — раздел 1, шаг 5 |
| SMS не уходит | Разрешение SMS; этому номеру уже отвечали < 30 мин назад; номер скрыт/короткий |
