# CallShift 0.8.38-send-limit

## Лимит автоответов MAX теперь настраивается

Лимит (защита от зацикливания сценария, не ограничение нормальной работы) раньше был жёстким — 20 сообщений в сутки. Теперь он настраивается:

- **«Технические настройки MAX»** → кнопка **«Лимит автоответов MAX в сутки: N»** → введите любое число **от 1 до 1000** → «Сохранить».
- Действует сразу, сохраняется в приложении, переживает перезапуски.
- По умолчанию — 20.
- Текст предупреждения при включении отправки тоже показывает актуальный лимит.

Верхняя граница 1000 оставлена как предохранитель: даже при сбое нельзя разослать неограниченное количество сообщений.

## Обновление

Установите 0.8.38 поверх. Обучение, лимит_attempts резерв на текущие сутки и настройки сохраняются.
