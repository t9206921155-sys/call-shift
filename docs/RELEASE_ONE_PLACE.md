# CallShift 0.8.54-one-place

## Раздел «Мессенджеры»: один экран вместо разбросанных настроек и журналов

Экран пересобран на том же компоненте, что и проверенные экраны настройки (FormUi). Всё сведение — в одном месте:

- **Сводка:** «Готовых каналов: N из 3» и по каждому каналу одна строка-статус: «● Готов — …» или «● Настроить — Дальше: <точный шаг>».
- **Все кнопки рядом:** настройка MAX, аккаунт Telegram и имитация, правила SMS, защита/расходы, лимиты (1–1000, с счётчиками использованного прямо на кнопках).
- **Подробности — по «Подробнее ▸»** в каждом канале, свёрнуты.
- **Одна кнопка «Скопировать всё для поддержки»:** собирает в буфер обмена версию, модель телефона, Android, состояние служб, статусы каналов и 12 последних событий из журнала (время, канал, результат, причина). Это и есть «логи по ошибке» — теперь их место одно, и они приходят ко мне одним текстом.

Telegram — без обучения кнопки (два переключателя), MAX — по мастеру. Компактный APK для обычных телефонов — файл с «-arm64» в релизе.
