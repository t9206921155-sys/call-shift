# CallShift — полная инструкция по настройке

Версия приложения: 0.6.1-m2 и новее. Всё настраивается на телефоне, компьютер не нужен.

---

## Шаг 1. Установка

1. Скачайте APK (ссылку присылают после каждой сборки) и откройте его.
2. Если телефон спросит — разрешите установку из этого источника.
3. **Android 13+:** если позже какое-то разрешение будет серым «Ограниченная настройка»:
   Настройки → Приложения → CallShift → ⋮ (вверху справа) → **«Разрешить ограниченные настройки»**.

## Шаг 2. Роль — без неё CallShift не видит звонки

Есть два варианта, выберите один:

| Вариант | Что даёт | Как включить |
|---|---|---|
| **А. Звонилка по умолчанию** (рекомендуется) | Всё: сброс, SMS, свой экран звонка, «Недавние», T9, скрытые номера, уведомления о пропущенных | Главный экран → «Телефон» → система спросит «Сделать CallShift приложением для звонков?» → **Да**. Или: Настройки → Приложения → Приложения по умолчанию → **Телефон** → CallShift |
| **Б. Только фильтр звонков** | Сброс и SMS по правилам, звонилка остаётся штатной. Скрытые номера **не** обрабатываются (ограничение Android) | Главный экран → кнопка «Выдать роль перехвата». Или: Приложения по умолчанию → **Определитель номера и спам** → CallShift |

Проверка: верхняя карточка на главном экране показывает статус без красного «Внимание».

## Шаг 3. Разрешения

Главный экран → **«Запросить разрешения»** → разрешите всё:

| Разрешение | Зачем | Без него |
|---|---|---|
| Телефон | видеть звонки и **определять SIM** | правила с выбранной SIM не сработают |
| Контакты | условия «только контакты / незнакомые», имена, фото | эти условия никогда не срабатывают |
| Журнал звонков | вкладка «Недавние» | «Недавние» пустые |
| SMS | автоответ SMS | SMS не уходят |
| Уведомления | пропущенные, напоминания | уведомлений нет |
| Микрофон (спросит при первой записи) | запись разговора | записи нет |

## Шаг 4. Батарея (обязательно на Realme / OPPO / Xiaomi / Huawei)

Иначе система может «усыпить» приложение.

- Настройки → Батарея → найдите CallShift → **«Без ограничений»**.
- Realme/OPPO: Настройки → Приложения → CallShift → Использование батареи → включите **«Разрешить фоновую активность»** и **«Автозапуск»**.
- Xiaomi: Безопасность → Разрешения → Автозапуск → CallShift.

## Шаг 5. Главный переключатель

Верхняя карточка → переключатель **CallShift** должен быть **включён**. Выключен — все звонки проходят как обычно, правила не работают.

## Шаг 6. Правило «Сбрасывать все звонки» — по полям

Главный экран → **＋** (круглая кнопка внизу).

| Поле | Что выбрать | Пояснение |
|---|---|---|
| Название | «Все звонки» | любое |
| Для каких звонков | **Все звонки** | включая контакты и незнакомые |
| Номер (шаблон) | **оставьте пустым** | заполните, только если нужно правило для конкретного номера/префикса, например `+7495*` |
| Порядок проверки | **Проверять последним** | чтобы исключения (например, «контакты — пропускать») стояли выше |
| SIM | **Любая SIM** | ⚠ выбирайте конкретную SIM, только если правило нужно для одной карты |
| Когда действует | **Всегда** | или расписание: будни 9–18, ночь 23–7 и т. п. |
| Куда направить звонок | **Ничего не делать** | переадресация на другой номер — отдельная тема |
| Что сделать со звонком | **Сбросить** или **Сбросить и записать в пропущенные** | «Без звука» — звонок идёт, но телефон молчит; «Пропустить» — ничего не делать |
| SMS-автоответ | текст или пусто | уйдёт с той же SIM, на которую звонили |

Нажмите **«Протестировать номер»** — введите номер, приложение скажет, что будет с таким звонком. Затем **«Сохранить правило»**.

На главном экране у правила должна быть **красная полоса** слева и включённый переключатель.

### Что значат варианты «Что сделать со звонком»

- **Сбросить** — звонящий слышит «занято»/отбой, у вас звонок не звучит.
- **Сбросить и записать в пропущенные** — то же, но звонок появится в «Недавних» как пропущенный. Так и задумано: запись в пропущенных — это **не** признак того, что правило не сработало. Смотрите журнал CallShift.
- **Без звука** — звонок продолжается беззвучно, можно ответить.
- **Пропустить** — звонит как обычно (для правил-исключений).

### Готовые схемы

- **Незнакомые — сбрасывать, контакты — пропускать:** одно правило «Для: Только незнакомые» → «Сбросить».
- **Разный SMS контактам и незнакомым:** правило 1 «Только контакты», порядок «Первым», SMS «Перезвоню». Правило 2 «Все звонки», порядок «Последним», SMS «Кто вы?». Срабатывает только первое подошедшее.
- **Ночью тишина, кроме близких:** близких — в «Белый список»; правило «Все звонки», «Ночью 23–7», «Сбросить».
- **Отпуск:** «Автоответчик» на главном экране → текст «Я в отпуске до …» → срок. Или правило со сроком действия «с даты / по дату».

## Исключения — эти звонки никогда не сбрасываются

1. **Белый список** (главный экран → «Белый список»).
2. **Повторный звонок** с того же номера **в течение 3 минут** после сброса — проходит («значит, срочно»).
   Отключается: карточка «Автоответчик» → «Настроить» → «Повторный звонок…».
   ⚠ При проверке не звоните себе два раза подряд — второй звонок пройдёт специально.
3. **Экстренные номера** (112 и т. п.).
4. **Скрытые номера** — только если CallShift **не** звонилка по умолчанию (Android их не показывает фильтрам).

## Как проверить, что всё работает

1. Попросите кого-то позвонить **один раз**.
2. Откройте **«Журнал»**. Запись с красной меткой **«⊘ Сброшен: правило «…»»** — работает.
3. Если метка зелёная **«✓ Прошёл»** — под ней написано **«Почему не сработали правила»** по каждому правилу. Частые причины:

| Причина в журнале | Что сделать |
|---|---|
| не удалось определить SIM звонка | в правиле поставьте **«Любая SIM»**; выдайте разрешение «Телефон» |
| звонок пришёл на другую SIM | выберите нужную SIM или «Любая» |
| сейчас не по расписанию | проверьте «Когда действует» |
| срок действия истёк / не начался | проверьте даты |
| номер есть / нет в контактах | проверьте «Для каких звонков» |
| нет доступа к контактам | дайте разрешение «Контакты» |
| выключено | включите переключатель у правила |
| повторный звонок — пропущен как срочный | это исключение (см. выше) |
| номер в белом списке | уберите из белого списка |
| главный переключатель выключен | включите CallShift вверху |

Если в журнале **нет записи** о звонке — у CallShift нет роли (шаг 2) или его «усыпила» батарея (шаг 4).

## Экран звонка и звонилка (если CallShift — звонилка по умолчанию)

- **Набор:** T9-подсказки по имени и номеру, долгое «0» — «+», долгое «1» — голосовая почта, долгое нажатие на номер — вставить.
- **Вкладки:** «Недавние» (цвет — тип звонка), «Контакты» (поиск). Долгое нажатие на строку — меню.
- **⋮ в звонилке:** обои и фон, записи разговоров, примечания, в контакты, SMS, белый список, настройки SIM.
- **Входящий:** проведите вправо — ответить, влево — отклонить. «Напомнить», «Сообщение», «Без звонка».
- **Разговор:** Запись · Удержать · Добавить вызов / Без звука · Видео · Примечания / Динамик · Завершить · Панель набора.
- **Тема:** кнопка «Тема» над списком правил.
