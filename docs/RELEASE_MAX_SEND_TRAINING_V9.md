# CallShift 0.8.31-send-training-v9

## Изменение

Если реальная проверка остановилась на кнопке отправки, а обученной кнопки ещё нет, сообщение теперь прямо говорит, что делать: нажать «Обучить кнопку отправки MAX» на экране CallShift, один раз показать стрелку и повторить тест. Тест без обучения падает всегда — порядок обязателен.

Обучение на 0.8.30+ уже исправлено под ваш MAX (стрелка без метки «кликабельная», исчезает после отправки, автоввод текста). Осталось пройти его один раз.

## Порядок

1. «Обучить кнопку отправки MAX» → «Начать обучение».
2. В MAX: безопасный чат (с самим собой или `+79206921155`), ждать «Текст введён. Нажмите синюю стрелку ОДИН раз».
3. Нажать стрелку → «Кнопка отправки распознана и сохранена».
4. «Проверить без отправки» → тестовая отправка.
