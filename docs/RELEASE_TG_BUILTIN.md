# CallShift 0.8.47-tg-builtin

## Настройка Telegram для 1000+ телефонов: без обучения и без переноса

Кнопка отправки Telegram теперь определяется **встроенным правилом самого приложения**: среди элементов ряда ввода с признаком «отправить» берётся самый правый — Telegram всегда держит кнопку отправки правее микрофона и скрепки. Обучение не нужно вовсе.

Настройка на каждом телефоне сводится к двум переключателям:

1. Включить службу «CallShift — Telegram (имитация касаний)» в спец. возможностях Android.
2. «Мессенджеры» → Telegram → «Аккаунт Telegram и имитация» → включить «Отправлять имитацией касаний» и «Разрешить реальную отправку».

Пункт «Обучить кнопку отправки» остался как запасной режим для нестандартных сборок Telegram — обычная настройка его не касается. Перенос кодом (появился в 0.8.43 для MAX) остался как удобство, в массовой установке не участвует.

Защита прежняя: подтверждение номера, одна попытка, без повторов, суточный лимит, честные итоги. MAX настраивается по встроенному мастеру «Настройка MAX» (кнопка — константа, обучение один раз на устройстве).
