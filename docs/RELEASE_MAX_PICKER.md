## CallShift 0.8.6-max-picker — распознавание окна выбора MAX

Экспериментальная версия, versionCode 38. Постоянный ключ и пакет сохранены.
Устанавливается поверх предыдущей версии. Реальное распознавание на устройстве
пользователя ещё не подтверждено: не объявляем, что причина его отказа доказана.

### Исправления
- Ранее все отказы обучения возвращали null, без отчёта. Теперь обучение само
  запускает диагностику v5, показывает конкретный код и объяснение в настройках.
  На этом же экране есть «Показать / скопировать отчёт распознавания».
- При недоступном active root можно получить корень единственного сфокусированного
  окна приложения через стандартный Accessibility API. Флаг получения окон включён
  в XML и при подключении службы. Фоновые окна для кликов не выбираются.
- Поддержаны подписи через contentDescription, только если текст элемента отсутствует,
  и пробелы/переносы строк. Конфликтующий видимый текст описанием не заменяется.
- Поддержана кликабельная иконка рядом с некликабельной подписью: требуется небольшой
  общий контейнер, одна подпись варианта и единственный элемент нажатия. Контейнер
  не может быть корнем, списком или содержать второй вариант.
- Повтор подписи в описании и тексте допускается только при совпадении цели нажатия.
  Разные цели для одной подписи и общий элемент для двух вариантов запрещены.
- Доступность системного пакета, заголовок окна, обе подписи, структура и уникальность
  по-прежнему проверяются. Неизвестный пакет не считается системным автоматически.
- Утрата окна при возвращении в CallShift не скрывает последнюю конкретную причину.

### Коды отчёта
NO_ROOT — Android не передал окно; PACKAGE_UNAVAILABLE — нельзя проверить системный
пакет; TITLE_MISSING — заголовок не найден; LABELS_MISSING — нет двух подписей;
ROW_UNAVAILABLE — нет отдельного элемента нажатия; ROW_AMBIGUOUS — неоднозначность;
READY — распознавание прошло. В отчёте только коды и счётчики, не имена пакетов,
resource IDs, подписи, номера SIM или переписка. Хранение в памяти, максимум 12
записей распознавания, отдельно от максимум 24 кадров MAX. Очистка удаляет оба набора.

### Проверка
MAX: эксперимент → Аккаунт отправителя по SIM → Изучить окно выбора двух MAX.
Оставьте окно выбора открытым на 3 секунды, ничего не выбирайте. Нажмите «Отмена»
или «Назад» и вернитесь. Если «Окно распознано» нет, здесь же откройте и скопируйте
отчёт распознавания. Звонок и повторная настройка профиля чата для этого не нужны.
До успешной проверки реальную отправку не включать.

Unit-тесты: нормализация пробелов, description fallback без подмены текста,
одинаковые/разные цели повторяющихся подписей, ограничения и очистка отчёта,
прежние проверки маршрутизации и безопасности. Эти тесты не проверяют реальные
Android Accessibility узлы или навигацию на телефоне пользователя.
