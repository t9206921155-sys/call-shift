## CallShift 0.8.12-max-editor — подсказка пустого редактора

Эксперимент, versionCode 44, прежние пакет/подпись. Ставится поверх текущей версии;
настройки SIM → копия MAX, окна выбора и профиля чата сохраняются.

Изменено чтение редактора: при явном Android isShowingHintText подсказка признаётся
подсказкой, даже если отдельное hintText отсутствует. Ранее код требовал обе части
метаданных и мог принять подсказку за черновик. Если Android передал противоречащие
друг другу text/hintText, текст сохраняется как непустой. Без явного флага слово
«Сообщение» (и любое другое) само по себе не означает пустоту.

Это исправление конкретного случая неполных метаданных, а не заявление о том,
какие именно метаданные передаёт MAX на телефоне пользователя: скриншот их не содержит.
Поле автоматически не очищается, защиту настоящего черновика не отключаем.

В диагностике v8 добавлены Editor flags только для выбранного редактора сообщения:
наличие text/hint, их равенство, isShowingHintText, фокус, наличие выделения и результат
распознавания пустоты. Тексты поля, содержимое переписки, длины текста, позиции
выделения, имена и ID в этот раздел не попадают. Сброс диагностики очищает признаки.
Сообщение об отказе теперь допускает нераспознанную подсказку, а не утверждает,
что пользователь обязательно оставил черновик.

Проверка: «Проверить каналы / тестовый ответ» → выбранная SIM и номер →
«MAX: тест навигации БЕЗ сообщения». Не перенастраивать SIM/профиль. Ничего не
стирать в визуально пустом поле сообщения. При повторной остановке нужен отчёт v8,
не скриншот переписки. Реальную отправку до успешной проверки не включать.

Unit-тесты: явная подсказка с/без отдельного hintText; настоящий текст, включая
буквальное «Сообщение» без флага; противоречащие метаданные; очистка диагностики.
Реальная работа Accessibility на устройстве пользователя пока не проверена.
