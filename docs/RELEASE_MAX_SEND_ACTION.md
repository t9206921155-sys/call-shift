## CallShift 0.8.22-max-send-action

versionCode 54, постоянная подпись, обновление поверх текущей версии.

### Подтверждённый этап
На новых скриншотах тестовый текст уже введён в MAX, отправка разрешена; результат —
«Кнопка отправки не определена однозначно. Черновик оставлен в MAX». Исправления ниже
касаются только поиска действия отправки. По изображению нельзя узнать подпись/ID/
действия, предоставленные Android, поэтому точный подтип отказа пока неизвестен.

### Изменения
- Явная подпись «Отправить»/Send допускается без resource ID. Раньше отсутствие ID
  отбрасывало даже явно подписанную доступную кнопку.
- Проверяются и текст, и contentDescription, а не только первая непустая строка.
  Поддержана подпись с суффиксом роли «, кнопка»/«, button».
- Для неподписанной иконки допускается ограниченный список явных MAX resource ID
  отправки (send_button, chat_input_send_button и т. п.). Синий цвет, стрелка и
  расположение справа сами по себе не разрешают нажатие.
- Подпись может принадлежать неактивному дочернему элементу, а ACTION_CLICK — его
  ближайшей обёртке. Обёртка допускается только без редактора, пароля и других
  действий, с единственной подписью отправки и без конфликтующего назначения.
- Если один компонент представлен подписанными родителем и единственным действующим
  ребёнком, выбирается ребёнок. Два соседних действия отправки остаются неоднозначностью.
- Кандидаты из прокручиваемой истории исключены: сообщение с текстом «Отправить» не
  становится кнопкой. Вложения, микрофон, запись, видео, меню, отложенная отправка и
  другие конфликтующие действия не принимаются за отправку текста.
- Если после ввода кнопка ещё не появилась, ожидание до 1,5 секунды без повторного
  ввода/резервирования/нажатия. Два кандидата останавливают сценарий сразу.
- Первичный и окончательный поиск используют один метод; перед действием заново
  проверяются точный текст, получатель, SIM/маршрут, окно и та же кнопка. Жеста по
  изображению стрелки или скрепки нет. Автоматический повтор не добавлен.

### Проверка на телефоне
Установить поверх. Старый оставшийся тестовый черновик удалить ВРУЧНУЮ, если он точно
не нужен: приложение его не стирает и не отправляет задним числом. Если его уже
отправили вручную, не пытаться автоматически повторить то же сообщение.
Затем «Автоответ MAX → Дополнительно → Начать новую проверку без отправки», после
успеха — разрешение и одна тестовая отправка. SIM, копию и карточку переучивать не надо.
Прежние интервалы и лимит 5 реальных попыток за сутки сохраняются.

Unit-тесты: подписи без ID, ID без подписи, суффиксы ролей, запрет скрепки/голоса/стрелки,
обёртки с несколькими действиями/редактором, устранение только вложенного дубликата.
Выпускной workflow прогоняет весь набор, собирает APK и проверяет постоянную подпись.
Реальное нажатие кнопки в этой версии MAX и доставка на телефоне пока не подтверждены.
Если Android не предоставляет ни смысловой подписи, ни поддерживаемого ID/действия,
сценарий по-прежнему останавливается, сохраняя черновик.
